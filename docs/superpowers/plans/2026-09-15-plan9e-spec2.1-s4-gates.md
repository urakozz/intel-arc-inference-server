# Spec 2.1 / S4 - the model gates on the L0 backend, in both builds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `prefill_gate_test`, `prefill_consistency_test` and `prefill_determinism_test` run on the L0 backend and pass - in the full build, and in a second build configured without the SYCL component - which is spec §2 bar 3.

**Architecture:** The three tests take the backend as one more positional argument (default: the build's default backend) and are built in every configuration; CMake registers them twice in the full build (`…_test` = sycl-tla, `…_l0_test` = l0) and once (l0) otherwise. `tools/box.sh` learns a build directory and extra configure flags so `build-nosycl` (`-DB70_PREFILL=OFF`) lives beside `build` on the box.

**Tech Stack:** C++17, CMake/ctest, bash.

**Spec:** `docs/superpowers/specs/2026-09-15-spec2.1-l0-prefill-gemm-design.md` (§2 bar 3, §4 "Model gates", §5 S4)

## Global Constraints

- Branch `spec1.7-codex-exp`; never push. Every commit message ends with `Claude-Session: `.
- Build/test only via `tools/box.sh` (JOBS 44); gate runs are long: detached and polled.
