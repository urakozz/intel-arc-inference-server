# Contributing

Bug reports, measurements on other setups and patches are welcome. For anything larger than a small fix, open an
issue first so the approach can be agreed before you spend time on it.

## Contributor license grant

The project is offered under the AGPL-3.0-only and under a commercial license (see [LICENSING.md](LICENSING.md)).
That only works if the author may license every part of the code both ways, so each contribution needs this grant:

> I wrote this contribution myself, or I otherwise have the right to submit it. If I made it as part of my job, my
> employer allows me to contribute it.
>
> I keep the copyright in my contribution. I grant Jürgen Kozyrev a perpetual, worldwide, non-exclusive,
> royalty-free, irrevocable license to use, modify and distribute it, and to license it to others, under the
> AGPL-3.0-only and under commercial license terms as part of this project.

To sign off, add this line to the description of your pull request:

```
I agree to the contributor license grant in CONTRIBUTING.md.
```

A pull request without that line cannot be merged.

## Third-party code

Do not paste code from other projects into a contribution. If a change needs third-party code, say so in the pull
request, with its source and license, so it can be placed under `third_party/` with its license kept.
