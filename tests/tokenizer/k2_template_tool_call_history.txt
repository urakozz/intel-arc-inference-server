# Tools
You may call one or more tools to assist with the user query.

Available tools are:

<ifm|tools>
## read
Read a file from the workspace.
Returns the lines numbered from 1.

**Parameters**
- `filePath` *(string, required)* - Absolute path of the file.
- `limit` *(integer)* - Lines to read.
  - Default: `2000`
- `offset` *(integer)* - Line to start from (1-based).
</ifm|tools>

The complete set of callable tool names is: read. Call one of these exact names. No other tool exists, whatever a task description, a skill file, or a previous turn may imply; a call to any other name fails and is not retried for you.

When calling tools, you MUST follow the tool-call format below:

Wrap all tool calls in a single <ifm|tool_calls></ifm|tool_calls> block. For each call, write the function name at the start of <ifm|tool_call>, followed by paired <ifm|arg_key> and <ifm|arg_value> tags for each argument:

<ifm|tool_calls>
<ifm|tool_call>$FUNCTION_NAME
<ifm|arg_key>$PARAMETER_NAME</ifm|arg_key>
<ifm|arg_value>$PARAMETER_VALUE</ifm|arg_value>
...
</ifm|tool_call>
</ifm|tool_calls>

String and scalar parameters should be written as plain text. Array and object parameters should be written as JSON literals.<|ifm|im_end|><|ifm|im_start|>user
