# Tools
You may call one or more tools to assist with the user query.

Available tools are:

<ifm|tools>
## read
Read a file from the workspace.
Returns the lines numbered from 1.

**Parameters**
- `filePath` *(string, required)* - Absolute path of the file.
- `limit` *(integer)* - Lines to read.
  - Default: `2000`
- `offset` *(integer)* - Line to start from (1-based).

## todowrite
Write the session's todo list.

**Parameters**
- `todos` *(array of object, required)* - The whole list.
  - Items *(object)*
    - `content` *(string, required)*
    - `id` *(string, required)*
    - `priority` *(string, required)*
      - Allowed values: `high`, `medium`, `low`
    - `status` *(string, required)*
      - Allowed values: `pending`, `in_progress`, `completed`

## glob
Find files by pattern.

**Parameters**
- `path` *(anyOf[string or null])* - Directory to search; the workspace when null.
  - Default: `None`
  - anyOf:
    - Variant 1 *(string)*
    - Variant 2 *(null)*
- `pattern` *(string, required)*
</ifm|tools>

The complete set of callable tool names is: read, todowrite, glob. Call one of these exact names. No other tool exists, whatever a task description, a skill file, or a previous turn may imply; a call to any other name fails and is not retried for you.

When calling tools, you MUST follow the tool-call format below:

Wrap all tool calls in a single <ifm|tool_calls></ifm|tool_calls> block. For each call, write the function name at the start of <ifm|tool_call>, followed by <ifm|arg_key>, <ifm|arg_type>, and <ifm|arg_value> tags for each argument:

<ifm|tool_calls>
<ifm|tool_call>$FUNCTION_NAME
<ifm|arg_key>$PARAMETER_NAME</ifm|arg_key>
<ifm|arg_type>$ARGUMENT_TYPE</ifm|arg_type>
<ifm|arg_value>$PARAMETER_VALUE</ifm|arg_value>
...
</ifm|tool_call>
</ifm|tool_calls>

Use the parameter type shown in the tool definition. If that type contains anyOf or oneOf, use the actual argument value type instead. String and scalar parameters should be written as plain text. Array and object parameters should be written as JSON literals.<|ifm|im_end|><|ifm|im_start|>user
