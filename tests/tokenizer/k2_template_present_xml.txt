# Tools
You may call one or more tools to assist with the user query.

Available tools are:

<ifm|tools>
<function name=read><description>Read a file from the workspace.
Returns the lines numbered from 1.</description><parameters><param name=filePath type=string required=true>Absolute path of the file.</param><param name=limit type=integer default=2000>Lines to read.</param><param name=offset type=integer>Line to start from (1-based).</param></parameters></function>
<function name=todowrite><description>Write the session's todo list.</description><parameters><param name=todos type=array[object] required=true>The whole list.<items type=object><param name=content type=string required=true/><param name=id type=string required=true/><param name=priority type=string required=true enum="high"|"medium"|"low"/><param name=status type=string required=true enum="pending"|"in_progress"|"completed"/></items></param></parameters></function>
<function name=edit><description>Replace text in a file.</description><parameters><param name=filePath type=string required=true/><param name=newString type=string required=true/><param name=oldString type=string required=true>Text to replace; must be unique unless replaceAll.</param><param name=replaceAll type=boolean default=False/></parameters></function>
</ifm|tools>

The complete set of callable tool names is: read, todowrite, edit. Call one of these exact names. No other tool exists, whatever a task description, a skill file, or a previous turn may imply; a call to any other name fails and is not retried for you.

When calling tools, you MUST follow the tool-call format below:

Wrap all tool calls in a single <ifm|tool_calls></ifm|tool_calls> block. For each call, write the function name at the start of <ifm|tool_call>, followed by paired <ifm|arg_key> and <ifm|arg_value> tags for each argument:

<ifm|tool_calls>
<ifm|tool_call>$FUNCTION_NAME
<ifm|arg_key>$PARAMETER_NAME</ifm|arg_key>
<ifm|arg_value>$PARAMETER_VALUE</ifm|arg_value>
...
</ifm|tool_call>
</ifm|tool_calls>

String and scalar parameters should be written as plain text. Array and object parameters should be written as JSON literals.<|ifm|im_end|><|ifm|im_start|>user
